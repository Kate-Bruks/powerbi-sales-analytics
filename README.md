# E-Commerce Performance & Analytics Dashboard (Olist Dataset)

An end-to-end Power BI analytics dashboard built to analyze sales performance, logistics efficiency, payment structures, and customer feedback for the Olist E-Commerce dataset.

---

## 📊 Project Overview

This Power BI project provides actionable business insights across 4 key operational areas:
1. **Sales Performance:** Revenue trends, average check size, conversion rates, and product category analysis.
2. **Logistics & Delivery:** Order cycle time (C2D), shipping values, regional market distribution, and seller performance.
3. **Payments Analysis:** Preferred payment methods, installment adoption rates, and average transaction values.
4. **Customer Feedback:** Customer review scores, sentiment breakdown, and response times.

## 🛠 Features & DAX Implementations

- **Dynamic Metric Switching:** Interactive line charts allowing users to toggle metrics (AVG Check, Leads, Sales, Sales_CNT) dynamically.
- **Data Modeling & Relationships:** Star Schema architecture linking orders, customers, products, sellers, and payments.
- **Custom DAX Calculations:**
  - Time Intelligence & Trend Analysis.
  - Custom KPI indicators for delivery SLAs and review score distributions.
- **Interactive Navigation:** Custom sidebar navigation for seamless transitions between Sales, Logistics, Payments, and Feedback views.
